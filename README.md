# 阿布的成长探索 · 教师自主练习

适合老师扫码后在自己的手机上独立完成。无需登录、课堂号或讲师控制台。

## 内容

10项个人练习：自我画像、支持网络、价值排序、生涯探索、情绪圆、小步行动、六顶思考帽、沟通表达、学习回忆和行动计划。覆盖原手册七个主题。

- 响应式手机页面，随时暂停、继续；本机保存练习记录。
- 提供练习提示、手册图片与出处、理论阅读线索。
- 可导出可读记录或JSON备份，不向服务器提交答案。
- 全部图片、样式和脚本内嵌于index.html，无第三方网页依赖。外部参考链接需联网打开。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch，选择 main / (root)，保存。发布成功后的网址以GitHub Pages设置返回的网址为准。

## 记录说明

页面下载需要网络，练习答案仅保存于当前设备浏览器localStorage，不上传至GitHub或讲师。隐私模式、清理浏览器数据或更换浏览器可能丢失记录，请及时导出备份。

## 素材

精选改编自用户提供的《苏州市平江中学校课程手册—家校社协同育人》。各练习标明PDF与印刷页码，图片来源与原作说明见页面“我的记录”。本网站不是原书逐页复制，不作为心理测评或诊断工具。
